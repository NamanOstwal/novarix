## Overview

**Novarix** is a full-stack sovereign enterprise AI automation platform engineered for population-scale deployment with zero external data egress, customer-owned KMS isolation, and low-latency bare-metal clusters.

- **Superconscious Aesthetic Design**: Curated `#0C0B0C` cosmic obsidian dark palette, multi-layer rotating border stroke accents, and feathered slimy blob simulation.
- **Autonomous Multi-Agent Swarms**: End-to-end operational task execution across banking, insurance, healthcare, and logistics.
- **22 Indic Languages & Dialects**: Speech synthesis (TTS), conversational ASR (STT), contextual translation, and spatial document intelligence.
- **500+ Enterprise Connectors**: n8n-style zero-ETL data streaming, CDC vector synchronization, and VPC private peering.
- **Multi-Platform Responsiveness**: Engineered for desktop viewports, mobile devices (iOS Safari, Android Chrome), and native embedded WebViews with notch/safe-area compatibility.

## Getting Started

### Prerequisites

- Node.js 18+ (tested on Node.js 24)
- npm or pnpm

### Installation

```bash
git clone https://github.com/NamanOstwal/novarix.git
cd novarix
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
npm run preview
```

---

## Deployment to Vercel

### Option 1: One-Click Vercel Dashboard Import
1. Visit [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and import `NamanOstwal/novarix`.
3. Framework preset will automatically detect **Vite**.
4. Click **Deploy**.

### Option 2: Deploy with Vercel CLI
```bash
npx vercel
```
Follow the interactive prompt to link and deploy to production.
